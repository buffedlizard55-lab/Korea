# Registry audit — 2026-08-21

> **Last verified: 2026-08-21**

## Scope and result

This review covers every non-header line in `data/deals.csv`. It checks the complete row shape, duplicate IDs, lifecycle/date fields, source-policy classification, city scope, and whether the new Seoul/Busan batch has a direct official manual-verification link and a concrete use instruction. It does **not** pretend that a local HTTP probe proves a live offer: the official page and the final on-site/app terms still control.

- Registry size after this sweep: **126 rows** (106 retained + 20 new).
- New records: **20/20 official-tier sources**, no new secondary/community/affiliate source, all with a source URL and redemption/use instructions.
- Structural checks: **no duplicate IDs; required fields, status vocabulary, ISO dates, active live-check safeguards, claim mappings, and source-confidence policy pass**.
- Counts by city: **Busan 31, Cheonan 3, Daejeon 5, Incheon 2, Nationwide 22, Seoul 63**.
- Counts by status: **active 79, expired 2, future 3, live-check 41, rejected 1**.
- Source tiers: **corroborated 9, official 104, operator 7, secondary 6**.

## Irregularities flagged for review

1. **Scope:** rows whose city is Nationwide, Incheon, Cheonan, or Daejeon are retained from the existing broader registry but are outside this Seoul/Busan expansion. Do not count them as Seoul/Busan deals.
2. **Non-primary active/live-check sources:** the existing registry still contains corroborated/secondary records. They are intentionally not labeled official and should not be upgraded without a brand/government page: `CHEONAN-TAXI`, `NATIONWIDE-MYEONGRYUN`, `NATIONWIDE-MOMSTOUCH`, `SEOUL-TONGIN`, `NATIONWIDE-ASHLEY`, `NATIONWIDE-HKB`, `NATIONWIDE-GIMBAP`, `NATIONWIDE-BUDGETCOFFEE`, `INCHEON-LOUNGE`, `SEOUL-ARISU`, `SEOUL-DEPT-CLEARANCE`, `SEOUL-STUDENT-FOOD`, `SEOUL-MANGWON`, and `BUSAN-LOCAL-FOOD`. Their current `live-check`/`corroborated`/`secondary` status is the honest flag.
3. **Dynamic new records:** `SEOUL-WATER-REUSE`, `SEOUL-NMK-CHILD`, `SEOUL-FUTURE-LAB`, `BUSAN-TAEJOON`, and `BUSAN-MMCH-ANNEX` remain `live-check` because booking slots, age/session limits, renovation, or current operating notices can change.
4. **Dated new record:** `SEOUL-GARDEN-SHOW-2026` is valid only through 2026-10-27 and some programs are paid or reservation-only.
5. **Existing records:** the prior 106 rows were not silently reclassified from a search snippet in this sweep. The table below shows their existing source tier and points back to the source for re-opening; see the 2026-08-18 independent audit for prior content corrections.
