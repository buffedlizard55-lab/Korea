# 🛵 Korean food-delivery apps as a tourist

Korea's delivery scene is world-class but was built for residents. Here's the 2026 reality
of each app: what's usable with a foreign card/phone, and the signup coupons worth grabbing.

> Last verified: 2026-08-03

## 1. Baemin (배달의민족) — the main event
- **English/中文/日本語 support launched 2026-02-04**; UI follows your phone's system language. 🟢 [DigitalToday announcement](https://www.digitaltoday.co.kr/en/view/2972/baemin-starts-in-app-support-for-english-chinese-and-japanese)
- Accepts overseas cards + Alipay+ / WeChat Pay; global-payment order volume grew ~300% YoY into late 2025.
- **First-order ₩10,000 coupon** for new users — official promise in the App Store listing. 🟢 <https://apps.apple.com/kr/app/id378084485>
- Guides report **guest checkout (비회원)** works without Korean ID verification using a foreign/hotel number; full accounts still ask for a Korean number for SMS verification. 🟡 [guide 1](https://askkoreatravel.com/food-delivery-in-korea-essential-2026-guide/) · [guide 2](https://latteinseoul.com/how-to-use-baemin-in-korea-english-guide/)
- Enter the **Korean address** (copy from Naver Map/KakaoMap) to avoid rider confusion.
- Add-ons: ~₩3,000 first-pickup coupon, brand-page weekday coupons, Baemin Club free-delivery trial (reported 1 month free).

## 2. Shuttle Delivery — the training-wheels option
- Fully English, intl. cards, **no Korean phone/ID**; service fees a bit higher and coverage is the Seoul core (Itaewon, Hongdae, Gangnam, Yongsan, etc.).
- Pro tip: **Klook sells Shuttle e-gift vouchers at a discount.** 🟢 <https://www.klook.com/activity/120381-food-delivery-in-korea/>
- Site: <https://www.shuttledelivery.co.kr>

## 3. Coupang Eats (쿠팡이츠)
- Largest welcome coupons in the market: first-order **coupon pack up to ₩20,000** via invite links (₩10,000–15,000 typical for general signups). 🟡 [source](https://choicemon.com/coupangeats-coupon/)
- **Practically requires a Korean phone number and Korean-issued card**; one tourist guide warns "Tourists should avoid" while another reports foreign cards work — treat as **expat-tier**. 🔀 [pro](https://globaltripplan.com/korean-food-delivery-apps/) · [contra](https://askkoreatravel.com/food-delivery-in-korea-essential-2026-guide/)

## 4. Yogiyo (요기요)
- Welcome coupons (~₩10,000) + Yogipass X (free-delivery subscription) first month free. 🟡 [2026 comparison](https://dasaja.co.kr/saja_guide/85)
- Korean-only UI and Korean phone verification — only worth it if someone on the trip has a verified Korean number.

## ⚠️ Universal gotchas
- **No tipping** anywhere — paying the listed fee is the full deal (₩2,000–4,000 typical delivery fee).
- "New user" = new **phone number + device**; reinstalls don't reset eligibility.
- Hotel deliveries: meet the driver in the **lobby** (many buildings restrict elevators; riders rarely speak English — keep the delivery note in Korean).
- First-order coupons die fast (7–30 days) and most have minimum spends — read the 쿠폰함 (coupon box) fine print in-app.
