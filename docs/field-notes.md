## 🏷️ Badge Upgrade Rules (from CONTRIBUTING.md)

- **🔴 → 🟡 → 🟢:** a first-hand photo/receipt that the deal worked at a named branch upgrades the badge. Add the date + branch + price to the doc and note it in the [verification log](verification-log.md).
- **Found a new deal?** Add it with a source link and the date, per [CONTRIBUTING.md](../CONTRIBUTING.md).
- **Deal died?** Don't delete it — strike it through, add the reason + date, move it under "Retired" (see [birthday-freebies.md](birthday-freebies.md) for the pattern).

## 🧾 What Counts as Proof

- Photo of the receipt with date + branch name
- Photo of the kiosk/coupon screen with the discount applied
- For ID checks: note *when* an ID was asked (alcohol? birthday coupon? tax refund? never?)
