# 🗣️ Korean Phrasebook for Deals & Dining

The 40 phrases that matter for ordering cheap, claiming coupons, and staying polite. Romanization is approximate — don't worry about perfect pronunciation, Koreans are patient with tourists.

> **Last verified: 2026-08-03** · Works everywhere in Korea (Seoul, Busan, etc.)

---

## 🧾 At the Kiosk / Café (`키오스크`)

| Hangul | Romanized | Meaning |
| --- | --- | --- |
| `키오스크` | ki-o-seu-keu | Self-order kiosk |
| `영어 있어요?` | yeong-eo iss-eo-yo? | Is there English? (kiosks have an 🇬🇧 button) |
| `이거 주세요` | i-geo ju-se-yo | This one, please (point at the screen/menu) |
| `할인 되나요?` | hal-in doe-na-yo? | Is there a discount? |
| `쿠폰 쓸 수 있어요?` | ku-pon sseul su iss-eo-yo? | Can I use a coupon? |
| `카드 돼요?` | ka-deu dwae-yo? | Do you take cards? |
| `아이스 아메리카노 한 잔` | a-i-seu a-me-ri-ka-no han jan | One iced Americano |

## 🍽️ At a Restaurant

| Hangul | Romanized | Meaning |
| --- | --- | --- |
| `점심 특선 있어요?` | jeom-sim teuk-seon iss-eo-yo? | Do you have a weekday lunch special? |
| `이거 뭐예요?` | i-geo mwo-ye-yo? | What is this? |
| `매워요?` | mae-wo-yo? | Is it spicy? |
| `덜 맵게 해주세요` | deol maep-ge hae-ju-se-yo | Please make it less spicy |
| `물 주세요` | mul ju-se-yo | Water, please (usually free) |
| `계산할게요` | gye-san-hal-kke-yo | Check, please |
| `포장할게요` | po-jang-hal-kke-yo | To go, please |
| `맛있어요!` | ma-sit-iss-eo-yo! | Delicious! |

## 🏪 At the Convenience Store / Market

| Hangul | Romanized | Meaning |
| --- | --- | --- |
| `1+1 / 2+1` | il deul-reo-il / i deul-reo-il | BOGO / buy-two-get-one (the shelf tags) |
| `이거 얼마예요?` | i-geo eol-ma-ye-yo? | How much is this? |
| `깎아 주세요` | kkakk-a ju-se-yo | Can you lower the price? (markets only, be friendly) |
| `엽전 주세요` | yeop-jeon ju-se-yo | Brass coins, please (Tongin Market) |
| `현금만 돼요?` | hyeon-geum-man dwae-yo? | Cash only? |

## 🧾 Tax Refund (Hypermarket / Airport)

| Hangul | Romanized | Meaning |
| --- | --- | --- |
| `즉시 환급 돼요?` | jeuk-si hwan-geup dwae-yo? | Is there an immediate tax refund? |
| `택스 프리 영수증 주세요` | tae-keu peu-ri yeong-su-jeung ju-se-yo | Please give me a tax-free receipt |
| `여권 필요해요?` | yeo-kwon pil-yo-hae-yo? | Do you need my passport? |

## 🙏 Politeness & Extras

| Hangul | Romanized | Meaning |
| --- | --- | --- |
| `감사합니다` | gam-sa-ham-ni-da | Thank you |
| `안녕하세요` | an-nyeong-ha-se-yo | Hello |
| `실례합니다` | sil-lye-ham-ni-da | Excuse me |
| `저는 채식주의자예요` | jeo-neun chae-sik-ju-ui-ja-ye-yo | I'm vegetarian |
| `알레르기 있어요` (e.g., `땅콩`) | al-le-reu-gi iss-eo-yo (ttang-kong) | I have an allergy (peanut) |
| `팁은 필요 없어요` | tip-eun pil-yo eops-eo-yo | No tip needed (you never need to say this — Korea has no tipping) |
