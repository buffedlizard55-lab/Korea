# 🎫 Pass & Payment Rules — Covers, Exclusions & Best Use Cases

Read this immediately before paying for any pass or travel-payment product. The same product can be excellent on one day and a waste on another.

> **Last verified: 2026-08-04** · Always pair this with the [Pass & Payment Value Dashboard](pass-value-dashboard.md).

---

## Discover Seoul Pass (DSP)

| Question | Answer |
| --- | --- |
| **Includes** | Eligible free attractions, listed discount partners, and the benefits attached to the specific current pass type. Card/mobile features differ by product. |
| **Does not include** | Every Seoul attraction, arbitrary food spending, separately charged add-ons, or an attraction after the activation window ends. |
| **Activation trigger** | The relevant pass validity starts when first used at an eligible attraction; confirm the live pass’s exact rule. |
| **Best use case** | A dense, pre-booked Seoul attraction day/period where the normal price of attractions you already want exceeds the pass price. |
| **Worst use case** | Buying it for one attraction, a slow café/shopping itinerary, or building an itinerary around places you do not truly want to visit. |
| **Before checkout** | Confirm live partner list, reservation requirements, attraction operating hours, current price, and activation window. |

🟢 [Official Discover Seoul Pass](https://www.discoverseoulpass.com)

## Climate Card Short-Term Pass

| Question | Answer |
| --- | --- |
| **Includes** | Eligible Seoul subway and bus rides during the selected short-pass period. |
| **Does not include** | Airport/intercity buses, excluded rail, and trips outside the defined coverage area. |
| **Activation trigger** | Starts on the day it is loaded; it cannot be loaded in advance for a later start. |
| **Best use case** | Multiple eligible subway/bus rides clustered into 1, 2, 3, 5, or 7 consecutive Seoul days. |
| **Worst use case** | Arrival/departure days dominated by airport travel, a slow walking day, or cross-region rail travel. |
| **Before checkout** | Add expected eligible fares, include any international-card machine fee, and confirm the route is in coverage. |

🟢 [Seoul Metropolitan Government terms](https://english.seoul.go.kr/climate-cards-and-single-journey-transit-tickets-now-accepting-international-credit-cards-no-cash-needed/)

## Visit Busan Pass (VBP)

| Question | Answer |
| --- | --- |
| **Includes** | Eligible attraction entry and listed discount partners for the selected time-based or quantity-based pass type. Physical-card transit features depend on the product. |
| **Does not include** | Every Busan attraction, an old blog’s partner list, any venue not on the current list, or food/cafe spending that does not meet a partner’s rules. |
| **Activation trigger** | Starts according to the selected product’s first use/entry rule; check the exact pass type before purchase. |
| **Best use case** | A Busan attraction day grouped geographically—e.g., several included Haeundae/Osiria or Songdo/Nampo stops—with live reservation availability. |
| **Worst use case** | Buying for a single attraction or hoping a small cafe discount will cover the pass cost. |
| **Before checkout** | Select a specific pass type; confirm live attractions, price, reservation rules, restaurant terms, and whether physical/mobile format affects transit. |

🟢 [Official Visit Busan Pass](https://www.visitbusanpass.com/)

## Busan Pay

| Question | Answer |
| --- | --- |
| **Includes** | Foreign-visitor prepaid payment, participating Dongbaekjeon merchant benefits, tourist information, and Visit Busan Pass purchase/use features. |
| **Does not include** | Guaranteed cashback at all stores, cashback at department stores/duty-free, or a discount if the merchant is not live-listed in the app. |
| **Activation trigger** | Obtain/register the prepaid card and load funds; individual merchant cashback applies only when the live app/merchant conditions are met. |
| **Best use case** | You will make several purchases at app-confirmed participating small businesses or buy VBP through the app when the cashback is currently offered. |
| **Worst use case** | Loading a large balance for one purchase at a mall/duty-free shop, where cashback does not apply. |
| **Before checkout** | Check current merchant, cashback cap/rate, QR extra benefit, balance/refund rules, and payment acceptance. |

🟢 [Busan Metropolitan City guide](https://www.busan.go.kr/bige/daily-busan/view?dataNo=69959&curPage=2&bbsNo=10&srchCl=Daily+Busan)

## KORAIL PASS

| Question | Answer |
| --- | --- |
| **Includes** | KORAIL-operated passenger trains allowed by the exact live pass terms. |
| **Does not include** | **SRT**, metropolitan subway, special tourist trains, or rail legs a traveler will not actually take. |
| **Activation trigger** | Use according to the selected pass’s live date/validity rules; passport name must match the pass. |
| **Best use case** | One traveler has enough long KORAIL-operated legs inside the pass window for individual live fares to exceed the pass price. |
| **Worst use case** | Only a Seoul–Busan return, SRT-heavy plan, city transit, or buying one pass to share among travelers. |
| **Before checkout** | Use [KORAIL PASS Math](rail-pass-math.md), compare SRT separately, check seat availability, and read refund/change terms. |

🟢 [KORAIL foreigner-pass terms](https://www.letskorail.com/ebizbf/EbizbfForeign_pr16100.do?gubun=1)

## Cheonan Tourism Taxi

| Question | Answer |
| --- | --- |
| **Includes** | A pre-booked driver/vehicle for the selected 4- or 8-hour tourism-taxi period; the driver also serves as local tourism support. |
| **Does not include** | Attraction admission, food, shopping, additional time, or a guaranteed seat after first-come supported inventory is gone. |
| **Activation trigger** | Reservation/availability confirmation for an eligible non-Cheonan visitor. |
| **Best use case** | A group sharing the 4- or 8-hour subsidized cost while visiting spread-out sites such as Independence Hall and Byeongcheon. |
| **Worst use case** | One traveler taking a simple station-to-one-attraction trip that public transit handles cheaply. |
| **Before checkout** | Confirm the live subsidy, resident eligibility, pickup point, route, group size, extra-hour rate, and cancellation terms. |

🟢 [Cheonan Culture & Tourism](https://www.cheonan.go.kr/tour.do) · 🟡 [corroborated terms](https://www.yna.co.kr/view/AKR20260224042200063)

## One last rule

If a product fails **any** of these three checks—**coverage**, **timing**, or **break-even value**—skip it and use normal tickets/payment. A pass is not a goal; it is only a way to lower a cost you were already going to pay.
